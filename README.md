## 1. Project Title
**Laundry Services Landing Page - Hero Section & Navigation Bar**

## 2. Assignment Objective
To build a modern, high-converting hero section and navigation bar strictly following traditional CSS layout techniques (`display: inline-block`, `width`, `vertical-align: middle`), without using Flexbox, CSS Grid, or Bootstrap.

## 3. Technologies Used
- **HTML5** (Semantic document structure)
- **CSS3** (Inline-block layout, viewport units, modern typography)

## 4. Features Implemented
- **Navigation Bar:**
  - Left-aligned brand logo (`Logo`).
  - Centered navigation links (`Home`, `Services`, `About Us`, `Contact Us`) using inline list items.
  - Right-aligned styled user badge (`Username`).
  - Constructed purely via `inline-block` and text alignment without Flexbox.
- **Two-Column Hero Section:**
  - Left column: Bold hierarchical typography ("Revitalize Your Clothes with Expert Laundry Services!"), highlighted keyword accent, descriptive copy, and a rounded call-to-action button ("Book a service today!").
  - Right column: High-resolution 3D laundry washing machine graphic (`hero-laundry.png`).
- **No-Scroll Design:** Fits gracefully into standard desktop viewport dimensions without unwanted scrollbars.
